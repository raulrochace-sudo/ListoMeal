LISTOMEAL — RECETAS CON INGREDIENTES DISPONIBLES

1. Descomprime el ZIP en una carpeta nueva.
2. Copia todo su contenido a la carpeta local de tu proyecto ListoMeal; acepta reemplazar archivos y conserva las carpetas.
3. En GitHub Desktop comprueba que se incluyen src/curatedCatalog.ts, src/localRecipes.ts, src/App.tsx, .gitignore, dist/index.html y dos archivos dist/assets.
4. Escribe el commit: Add meals using available ingredients
5. Presiona Commit to main y luego Push origin.
6. Espera a que Render indique Live y vuelve a cargar listomeal.com.

Prueba: marca milk, yogurt, cheese, tortillas, eggs, sour cream y hot dogs. Entre las tres primeras recetas deben aparecer burritos de huevo con salchicha, quesadillas de huevo con queso y huevos con queso en taza, sin ingredientes faltantes.

Este ZIP no contiene imágenes nuevas para las tres recetas; no se ha cobrado ninguna generación adicional.
