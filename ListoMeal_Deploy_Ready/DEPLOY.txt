LISTOMEAL — DEPLOYMENT READY

This package is prepared for a Python web host such as Render.

Render settings:
Build command:
pip install -r requirements.txt

Start command:
gunicorn server:app

Required secret environment variable:
OPENAI_API_KEY

IMPORTANT:
Never upload or paste your API key into server.py, index.html, GitHub, or this ZIP.
Add it only as a secret environment variable on your hosting provider.

The included render.yaml can configure most Render settings automatically.
